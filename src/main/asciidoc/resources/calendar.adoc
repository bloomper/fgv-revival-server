== Feed

A revival's events as an iCalendar feed, behind a secret link created with the GraphQL mutation `calendarFeedCreate`.
Calendar apps have no access token, so the link is the credential.
`404 Not Found` for a malformed, unknown or revoked link, and when the person it belongs to may no longer see the revival.
