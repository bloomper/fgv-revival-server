[[introduction]]
== Introduction

Nyuppsättning Server is the backend of Nyuppsättning, which supports the steering groups of Chalmersspex revivals.

The purpose of this documentation is to provide details on how to develop within Nyuppsättning Server and how to integrate Nyuppsättning Server into another application, e.g. a web application.
