[[introduction]]
== Introduction

Nyuppsättning Server's API is xref:graphql-api-guide.adoc[GraphQL].
A few endpoints are plain HTTP, for what GraphQL does not suit: files and images.
Like GraphQL, they are thin adapters over the services, which decide who may do what.

[[http_verbs]]
== HTTP verbs

|===
| Verb | Usage

| `GET`
| Used to retrieve a file or an image

| `POST`
| Used to upload a file

| `DELETE`
| Used to remove a file
|===

[[http_status_codes]]
== HTTP status codes

|===
| Status code | Usage

| `200 OK`
| The request completed successfully.

| `204 No Content`
| There is nothing to return, e.g. a spex without a poster, or a removal has been applied.

| `400 Bad Request`
| The request was malformed, e.g. a receipt without a file.

| `401 Unauthorized`
| The request has no valid access token.

| `403 Forbidden`
| The user lacks the role the request requires.

| `404 Not Found`
| The requested resource does not exist, or the user may not see it.

| `409 Conflict`
| Someone else changed the resource since it was read.

| `413 Content Too Large`
| The uploaded file is larger than 10 MB.

| `503 Service Unavailable`
| A service the request depends on, such as Spexregister or Swish, cannot be reached.
|===

[[roles]]
== Roles

Every endpoint but the calendar feed requires an access token from the `fgv-revival` client with the `USER` client role.
What the user may do beyond that follows from their roles in the revival, exactly as in the xref:graphql-api-guide.adoc#roles[GraphQL API].
